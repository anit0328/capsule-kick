# カプセルキック

カプセルから出てきたなかまを**キックして飛ばし**、敵の城をこわしていく横スクロールのブラウザゲームです。ガチャでなかまを集め、へんせいと武器で強くしながらステージを進めます。

- 遊ぶ: https://anit0328.github.io/capsule-kick/
- バージョン: Ver3.8

## 遊び方

1. **カプセルガチャ**でなかまを手に入れる（1回100コイン、10連は★3以上を1体保証）
2. **へんせい**でデッキ（最大10体）を組む。「おすすめ編成」でおまかせも可
3. **バトル**ではスロットを長押ししてため、はなすとキック。遠くへ飛ばすほど着地ダメージが上がる
4. 敵の城をこわせば勝ち。ワールドマップのステージを順に進める（5の倍数はボス）

## おもな特徴

- **なかま**: ★1〜★5のキャラ。キャラごとの「重さ」で飛び方が変わり、のっぽ・はね返し・超重量などの特性もある
- **三すくみ**: 武器（剣＞槍＞弓＞剣）と属性（水＞火＞雷＞水）。やけど・氷結・まひの状態異常あり
- **武器と盾**: 敵がたまに落とし、なかまが自動で拾って装備する。集めたものは武器庫で付け替えや一括売却ができる
- **ガチャ3弾**: 第1弾に加えて、第2弾はステージ1クリア、第3弾「スイーツキングダム」はステージ2クリアで開放。◀▶で台を切り替える
- **たいせん**: ルームIDか合言葉で友だちとリアルタイム対戦（10分・城HP3000）
- **そのほか**: カプセルキャノン、キャンディ回収、オート・2倍速、BGMと効果音、ログインボーナス

## 動かし方

ビルドは不要です。`index.html` 1ファイルだけで動きます。

```bash
# ローカルで確認する場合（どれか1つ）
npx serve .
python3 -m http.server 8000
```

Netlify や GitHub Pages など、静的ファイルを置けるサービスならそのまま公開できます。

### たいせんモードについて

たいせんは、WebSocket（MessagePack）で通信するマルチプレイ用サーバーにつないで動きます。接続先は `index.html` の中に書かれています。サーバーにつながらない環境でも、ほかのモードはふつうに遊べます。

## 技術メモ

- HTML / CSS / JavaScript の1ファイル構成。フレームワークや外部ライブラリは使っていない（フォントだけ Google Fonts から読み込む）
- 画像はCanvasで描画し、効果音・BGMはWeb Audio APIで生成している
- セーブデータはブラウザの localStorage に保存する
